# OnionHEN

This repository is closed.

I came into this community as a new developer, and I have always treated everyone and everything here with a great deal of respect.

I built this payload for myself. I never asked for anything in return.

There were people who stirred up trouble along the way. I didn't care at first. After a while, though, it started getting to me. I don't really want this kind of drama affecting my life.

So I have decided to close this repository.

OnionHEN has already been forked, and the open-source license is not an issue. If you are able and willing, I hope you will keep the project going.

OnionHEN has done what it came to do. It brought a few new improvements, and that is enough. Please look after the original project, and support it: [etaHEN](https://github.com/LightningMods/etaHEN).

I just want to go back to my life now. Thank you.
